Relative Power

Delta = (most recent − first) ÷ first × 100, within the selected dates. Colour: red ≤ −8% or ≥ +10%, amber −8% to −1%, green +1% to +9% — large swings are flagged red either way, as in the target sheet. Duplicate trials on the same date are averaged. Values are shown as recorded in the export; check the source file for any trial you want to verify.
